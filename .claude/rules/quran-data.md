# Quran data

- `data/quran/` is generated by `scripts/fetch-quran.ts` and committed. Never edit it by hand:
  change the script and run it again.
- Arabic: Tanzil.net, Uthmani script. Translation: Sahih International (English), fetched from
  the same verified source.
- The Tanzil licence requires the text to stay unaltered and attributed. Keep its licence notice
  in `data/quran/LICENSE` and keep the in-game credits.
