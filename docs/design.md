# Design

Stories of the Prophets is a personal study game. The religious rules in `CLAUDE.md` apply to
everything described here.

## Game concept

- **Map hub**: an illustrated map (Mesopotamia, Canaan, Egypt, Madyan, Arabia). Each location
  opens a chapter.
- **Witness perspective**: the player is an ordinary person living through the story (e.g. a
  traveller who finds Yusuf in the well). The prophet is present only through light, narration
  and how other characters react.
- **One mechanic per chapter** that fits the story's lesson (e.g. managing Egypt's grain through
  seven good and seven lean years in Yusuf).
- **Ayat journal**: playing a scene unlocks the ayat it is based on (Arabic + translation),
  collected in a journal the player can browse.
- **Source panel**: every scene can show the exact ayat and tafsir notes behind it.
- **Recurring words**: key Arabic words (sabr, tawakkul, shukr, ...) are tracked across chapters.
- **Reflection screen** at the end of each chapter with one question; answers are saved locally.
- **Credits screen**: shows the Tanzil attribution required by its licence, plus asset credits.

## Chapter plan

1. **Yusuf** (Surah Yusuf, 12): the first chapter, built as a complete vertical slice before
   any other chapter.

## Sources

- **Quran Arabic text**: Tanzil.net, Uthmani script.
- **Translation**: Sahih International (English), from the same verified source.
- **Tafsir**: Tafsir Ibn Kathir (e.g. via Quran.com).

## Planned layout

Story content is data, kept separate from code.

```
content/
  chapters/
    yusuf.json        # scenes (beats: narration and ayah refs), refs, certainty, mechanic config
  words.json          # recurring Arabic words and where they appear
data/
  quran/              # verified Arabic + translation, generated by scripts/fetch-quran.ts
scripts/              # fetch-quran.ts, content validation
src/
  scenes/             # Phaser scenes (map, chapter, journal, reflection)
  systems/            # game logic, pure TypeScript, no Phaser imports
  content/            # loaders + types for content files
  config.ts           # all tuning values
assets/
  CREDITS.md          # every asset with its licence
```
